# StepFit Shoes

Secure online shoe retail application built for ST6005CEM Security (CW2).

## Overview

A deliberately small e-commerce application demonstrating secure-by-design
development practices: authentication with multi-factor support, role-based
access control, secure session management, input validation, activity
logging, and defences against common OWASP Top 10 risks.

## Technology Stack

- **Frontend:** React (Vite)
- **Backend:** Node.js / Express
- **Database:** PostgreSQL
- **Containerisation:** Docker
